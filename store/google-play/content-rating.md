# Play Console: content rating (IARC questionnaire)

Play Console → **Policy and programs → App content → Content rating → Start questionnaire**.

## Step 1: Category
- **Email address:** ted.jacquet@edlight.org (IARC sends the certificate here)
- **Category:** **All other app types** (not Game, and not "Social or communication": messaging is a side feature of a ticketing app)
- Accept the IARC terms → **Next**

## Step 2: Questionnaire answers

| Question (IARC wording, paraphrased) | Answer | Reason |
|---|---|---|
| Violence: does the app contain violent content? | **No** | |
| Fear / horror content? | **No** | |
| Sexuality: nudity or sexual content? | **No** | Posters are moderated; nudity is against the Terms |
| Language: profanity or crude humour? | **No** | |
| Controlled substances: references to or depictions of drugs, alcohol or tobacco? | **Yes: references to alcohol** | Nightlife and party posters mention drinks/open bars |
| ↳ Is the use of these substances encouraged or glamourised? | **No** | |
| Crude humour? | **No** | |
| Gambling: real or simulated? | **No** | |
| Does the app sell or promote digital purchases / loot boxes? | **No** | Tickets are for physical events |
| **Does the app allow users to interact or exchange content with each other?** | **Yes** | Organizers publish events; attendees message organizers; friends and "who's going" |
| ↳ Can users share user-generated content (images, text)? | **Yes** | Event posters and descriptions, reviews, profiles |
| ↳ Can users communicate with each other (chat, messages)? | **Yes** (limited: attendee to organizer, organizer update broadcasts) | |
| ↳ Is there moderation? | **Yes** (admin moderation console: unpublish events, ban organizers) | |
| **Does the app share the user's current physical location with other users?** | **No** | |
| **Does the app allow users to purchase digital goods?** | **No** | |
| Does the app contain news or information about real-world violence? | **No** | |
| Is the app a web browser or search engine? | **No** | |

→ **Save** → **Next** → **Submit**.

## Expected result
Roughly **Teen / PEGI 12 / USK 12 / ClassInd 12**, with the interactive element
**"Users Interact"**. "Digital Purchases" and "Shares Location" must NOT appear. If IARC returns Mature/18+, re-check that alcohol was marked as *references* and not
*use*.

## Target audience (separate section, same App content page)
- **Target age groups:** tick **18 and over** only.
- *Why:* much of the catalogue is nightlife, and 18+ keeps the app out of the Families policy
  (no Designed for Families review, no teacher-approved requirements).
- **Could your store listing unintentionally appeal to children?** → **No**.
- Save.
